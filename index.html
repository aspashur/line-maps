About the data

“Ley lines” are a speculative cultural and historical concept, not scientifically established geographic structures. There is no universally accepted, authoritative global ley-line dataset. This map therefore starts without asserting that any particular alignment is real; import a dataset whose sources and methodology you can evaluate.

Map data © OpenStreetMap contributors. GPS is requested only after you select “My location”; your browser may require HTTPS or localhost. Distance is measured to the nearest point on an imported line, not necessarily along a route.
